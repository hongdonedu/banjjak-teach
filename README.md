# ⚡ 반짝이를 가르쳐요! 에너지 탐정단

초등 2학년 창의적 체험활동 에너지 프로그램 웹앱입니다. 아기 로봇 **반짝이**는 에너지에 대해 일부러 틀린 말을 하는 AI 티처블 에이전트예요. 아이들은 먼저 직접 확인한 뒤, 증거 종류가 붙은 이유 카드("왜냐하면…")를 골라 반짝이를 가르칩니다.

- **학생 화면:** https://hongdonedu.github.io/banjjak-teach/
- **기록 저장:** 구글 앱스스크립트(예전 반짝이 앱과 같은 주소, `doPost`)를 거쳐 같은 구글 시트에 저장돼요. 시트는 활동기록·대화기록·반짝이노트·도장판·졸업퀴즈입니다.
- **개인정보:** 학생 이름은 받지 않고 **반·번호만** 저장해요.

## 화면 구성(왼쪽 차례)
| 차례 | 내용 |
|---|---|
| 🏠 탐정 본부 | 미션 카드 6개. 선생님이 고른 차시에 ‘오늘의 미션’ 별표가 붙어요 |
| 미션 1~5 | 반짝이 말 듣기 → 내 생각 고르기 → 직접 확인하기 → 반짝이 가르치기 → 반짝이와 이야기 |
| 미션 6 | 반짝이 졸업 시험(몰래 넣은 실수 2개 찾기) → 졸업장 |
| 📒 반짝이 노트 | 우리 반이 가르친 문장 게시판(❤️) |
| ⭐ 에너지 지킴이 | 집에서 전기 아낀 날 도장 찍기 |
| 📝 마음 설문 | 사전·사후 구글 설문지를 화면 안에서 바로 응답 |
| 🔑 선생님 | 오늘의 미션 표시, AI 대답 켜기·끄기, 현황·최근 기록, 데이터 시트 열기 |

**미션 1~6은 모두 열려 있어요.** 아이들이 골라서 해요.

## 🧪 반짝이 실험실 — 준비물 없음
미션 2~5의 ‘직접 확인하기’는 화면 안 시뮬레이터로 해요(얼음·바람개비·전력 측정기 필요 없음). 미션 1은 진짜 교실을 둘러봐요.

| 미션 | 실험실에서 하는 것 |
|---|---|
| 2 햇빛 | 햇빛·그늘 얼음에 ‘5분 지나가기’ 3번 → 녹은 정도 비교 · 검은/흰/그늘 종이 눌러 온도계 보기 |
| 3 바람 | 살랑살랑·세게·멈추기로 바람개비 빠르기 비교 · 종이 조각 날리기 · 👓 바람 안경 · 🎤 입으로 불기(선택) |
| 4 꺼진 TV | 리모컨으로 켜고 끄기, 플러그 뽑기 → ‘전기 숫자 측정기’ 85 → 1 → 0 · 꺼진 TV의 빨간 불 찾기 |
| 5 전기 오는 길 | 카드 순서(발전소→전선→콘센트→전등) · 석탄/햇빛·바람 발전소 바꾸기 · 불 끄면 연기 줄기 |

- 학생 앱: 실험실에서 실제로 해 본 것은 ‘내가 확인한 것’에 자동 ✔ 되고, 시트 ‘확인한 것’ 칸에 `실험실: …`으로 남아요.
- **실험실만 따로:** https://hongdonedu.github.io/banjjak-teach/lab.html (3반 비교반·전자칠판 시연용, 기록 저장 없음, `?m=2`~`?m=5`로 바로 열기)
